它做三件事

掃描、比對、匯出——每一步都看得見來源與指令

01盤點

18 個分類並行掃描：Homebrew、Python、Node.js、Rust、Java、.NET、PHP、Ruby、Go、Swift、Deno、Bun、 R、VirtualBox、uv、全域指令、Chocolatey、系統工具。沒安裝的分類自動隱藏。

02比對

連上游比版本：brew outdated、PyPI、npm registry、rustup check、 Adoptium、.NET releases-index、GitHub releases，並回報 .NET 是否已 EOL。

03匯出

一鍵產生重建包：Brewfile、requirements-*.txt、 npm-globals.sh、gems.sh、 global.json 與 REBUILD.md。

18 個分類，依來源歸位

不是按「常用」分，而是按東西從哪來分

Homebrew Chocolatey Python Node.js Rust Java .NET PHP Ruby Go Swift Deno Bun R VirtualBox uv 全域指令 系統工具

同一個程式的多個指令會收在一起（例如 VirtualBox 的 12 支、R 的 2 支），收合時直接顯示版本。 npm／bun 全域套件留在 Node.js／Bun，不會重複列在「全域指令」。

找得到你裝過的 Agent CLI

工具列有一個 Agent CLI 篩選：claude、codex、gemini、aider、opencode、crush、qwen、ollama、 tripo、dreamina…不管是 npm、uv、Homebrew 還是手動下載的，一次跨分類列出來，並附上對應的更新指令。

claudeAI codexAI geminiAI tripo-cliAI dreamina-canvasAI ＋ 名單可自行擴充

只讀，不是口號

Envtally 的工作是「告訴你現況」，不是「幫你改」。所有更新與移除指令都只是可複製的文字。

  • 不會安裝、升級或移除任何套件
  • 不會改你的 shell 設定、PATH 或任何設定檔
  • 唯一會寫檔的是「匯出清單」，而且要你按了才寫
  • 掃描完全在本機；只有按「檢查更新」才會連公開 API
  • 沒有帳號、沒有遙測、沒有背景排程

安裝

目前版本 v0.4.0

macOS Apple Silicon · 11+

  1. 下載 .dmg 並開啟
  2. 把 Envtally 拖進「應用程式」
  3. 首次開啟：右鍵點 App →「打開」
未公證，所以第一次會提示「無法驗證開發者」——右鍵開啟即可。
若顯示「已損毀」，請下載 0.3.3 或更新版本（已修正簽章問題）。

Windows x64 · 10+

  1. 下載 setup.exe（安裝精靈）或 .msi
  2. 執行安裝
  3. SmartScreen 提示時：更多資訊 → 仍要執行
未簽章。Windows 版目前只經過 CI 編譯與單元測試，尚未實機長時間驗證；遇到問題請開 issue。
